# Data Lens – Country Data Comparison Dashboard

**DEPI – Digital Egypt Pioneers Initiative | Track: Junior Data Analysis**

Data Lens turns the raw World Bank WDI workbook (22 countries, 74 indicators, 2000–2025) into a clean data model and an interactive Power BI dashboard for comparing countries.

## Installation and requirements
- Windows with **Power BI Desktop** (free).
- Screen 1920 × 1080 or larger recommended.

## Configuration
1. Open `powerbi/DataLens.pbix`.
2. If asked for the data source, point it to `data/WDI_Data.xlsx` and click **Refresh**.

## Execution guide
Run locally by opening the `.pbix` file. Pages: Overview, Comparison, Trends, and a Country detail page (right-click a country → Drill through).
